依存更新の前後比較に必要な**現行値のベースライン**を計測する。`npm run dev` のコールドスタート時間、`npm run build` 後の `dist/` 合計サイズ、`npm audit` の現行 high/critical 件数を記録する。TASK-0007 で同条件の更新後値と比較するための前提作業。

## 主要実装項目

### dev コールドスタート計測 🔵

**信頼性**: 🔵 *NFR-001 の閾値「現行比 2 倍を超えない」より計測必須*

`node_modules` を保持したまま、Vite の dev cache を無効化したコールドスタートを 3 回試行し中央値を記録する。

- 手順: `rm -rf node_modules/.vite` → `npm run dev`（起動完了表示までを計測）
- 記録項目: 試行 3 回の秒数、中央値

### build 成果物サイズ計測 🔵

**信頼性**: 🔵 *NFR-002 の閾値「現行比 2 倍を超えない」より計測必須*

- 手順: `npm run build` → `dist/` 全体のサイズ（KB 単位）と主要ファイル個別サイズ
- 記録項目: 合計 KB、`assets/*.js` / `assets/*.css` 個別サイズ

### npm audit 計測 🔵

**信頼性**: 🔵 *NFR-101 「high/critical が増えないこと」より*

- 手順: `npm audit --omit=dev --json` の出力から `metadata.vulnerabilities.high` / `.critical` を抽出
- 記録項目: `low / moderate / high / critical` の件数

## 基本的なテスト要件

### 計測値の再現性 🔵

**信頼性**: 🔵 *科学的に妥当な計測手順より*
