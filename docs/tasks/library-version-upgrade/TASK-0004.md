## タスク概要

`main.js` 行545 の `geolocationControl._watchState === 'OFF'` 直接参照を撤去し、`GeolocateControl` の公開イベント `trackuserlocationend` で停止検知する形に書き換える。既存挙動（停止時に `userLocation = null`、`route` source を空に戻す）を維持する。

- **後続タスク**: [TASK-0005](TASK-0005.md)

## 主要実装項目

### `trackuserlocationend` イベント購読の追加 🔵

**信頼性**: 🔵 *architecture.md § REQ-501 撤去の設計 より*

`main.js` 行422付近（`geolocate` 購読の直後）に以下を追加：

```js
geolocationControl.on('trackuserlocationend', () => {
    userLocation = null;
});
```

採用 maplibre-gl 版で `trackuserlocationend` が無い／名称が違う場合は、最も近い公開イベント（例: `trackuserlocationstart` の対 / 状態変更イベント）に差し替える。

### `_watchState` 直接参照の削除 🔵

**信頼性**: 🔵 *requirements.md REQ-501 / dataflow.md § 3.2 より*

`main.js` 行545 の以下の行を削除：

```js
if (geolocationControl._watchState === 'OFF') userLocation = null;
```

`render` リスナー内には早期 return 条件（zoom < 7 / userLocation === null）のみを残す。

### 他箇所の不変性確認 🔵

**信頼性**: 🔵 *REQ-403 スコープ厳密化 より*

- `route` source 更新ロジック、`getNearestFeature`、レイヤー定義などは変更しない
- スコープ規律（依存更新 + REQ-501 のみ）を維持
