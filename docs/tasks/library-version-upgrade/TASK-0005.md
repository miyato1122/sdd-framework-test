## 注意事項

- **静的解析だけで判断しない**: メモ [[feedback_verify_ui_at_runtime]] に基づき、実ブラウザ目視を必須とする。
- **REQ-501 の挙動失敗時**: イベント名（`trackuserlocationend`）が採用版で異なる可能性。TASK-0004 に戻り、採用 maplibre-gl 版の公開イベント一覧で見直す。
- **タイル CDN の一時障害は除外**: OSM / 国土地理院のタイル CDN が一時的に応答しない場合は、本タスクの fail とはしない（コンソールに 4xx/5xx が出てもネットワーク要因として記録のみ）。
