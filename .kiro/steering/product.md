# Product Overview

防災ハザードマップ Web アプリ（書籍「位置情報アプリケーション開発実践編」応用編のサンプルコード）。日本全国を対象に、背景地図へ各種ハザードマップと指定緊急避難場所を重ね、利用者の現在地から最寄りの避難施設までの距離・経路を案内する PWA。

このリポジトリは同時に **SDD（仕様駆動開発）フレームワーク比較演習の検証台** でもある。アプリ本体は意図的に「枯れた素材」であり、変更の価値は機能的価値そのものより「その変更で SDD の何を検証できるか」で測られる（git-spec / cc-sdd / tsumiki / open-spec を同一題材で比較する）。

## Core Capabilities

- **背景地図 + ハザード重畳**: OSM ベースマップに、国土地理院ハザードポータルのラスタタイル（洪水・高潮・津波・土石流・急傾斜地崩壊・地すべり）を重ねる。
- **避難場所表示**: 指定緊急避難場所をベクトルタイル（自ホスト `skhb`）で表示し、クリックで属性ポップアップを提示。
- **現在地→最寄り避難所ナビ**: Geolocate で現在地を取得し、最寄り施設を判定、経路ライン描画と距離計算を行う。
- **3D 地形・陰影**: 地理院標高タイルから raster-dem を生成し、地形誇張と陰影を表示。
- **レイヤ不透明度操作 / PWA**: 重畳レイヤの切替・不透明度調整、manifest + Service Worker によるインストール可能化。

## Target Use Cases

- 平常時に居住地・移動先のハザードリスクと最寄り避難場所を事前確認する一般利用者。
- SDD フレームワークの挙動（要件→設計→タスク→実装の各ゲート、レビュー品質、検証エビデンスの扱い）を、現実的な小規模アプリ改修を通じて比較したい評価者。

## Value Proposition

- 公的データ（国土地理院・OSM）のみで完結し、認証・サーバ実装不要のクライアント単体で防災情報を提供できる軽量さ。
- 比較演習の観点では「小さく自己完結し、破壊的変更点が明確（依存更新・新機能・既存修正・構成移行）」という、フレームワーク横並び評価に適した統制された題材であること。
