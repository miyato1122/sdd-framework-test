# 実機スモークチェックリスト — basemap-switcher

本書は受け入れ基準（requirements.md の 1.1–6.4）に対応した**ブラウザ実機目視**のチェックリストです。tech.md／プロジェクト方針により UI・ライブラリ挙動は静的解析で断定せず、**実機目視はユーザーが実施**します（実装側＝本チェックリストの提供と自動検証可能範囲＝task 5.1 のクリーン環境健全性まで完了済み）。

## 前提・起動手順

- クリーン環境健全性（install/build/dev/preview）は task 5.1 で確認済み（当 Windows 環境では `npm ci` 不可のため `npm install` lockfile 整合を正準とする＝偽 green ではない既知特性）。
- 実機確認はモダンブラウザ（WebGL2）で実施。
- 起動: リポジトリルートで `npm run dev`（または `npm run build` 後 `npm run preview`）→ 表示された `http://localhost:<port>/` を開く。
- 各項目の判定欄に PASS / FAIL（FAIL は所見を併記）を記入。1 件でも FAIL があれば実装へ差し戻し（reviewer/debug 経由）。

## 1. 機能（背景地図の選択と切替）

- [ ] 1.1 地図の**左下**に背景地図切替コントロールが表示される（既存コントロールと別位置）。
- [ ] 1.2 コントロールに **4 つの選択肢**が識別可能なラベルで並ぶ（OpenStreetMap／地理院地図(標準)／航空写真／白地図）。
- [ ] 1.3 いずれかを選択すると**その背景のみ**が表示され、他 3 種は表示されない（排他）。
- [ ] 1.4 選択時にページ遷移・再読み込みなしで地図へ**即時反映**される。
- [ ] 1.5 現在選択中の背景地図が**チェック状態で明示**される（選択を変えると追従）。
- [ ] 1.6 初回起動時の背景が **OSM** で、従来の初期中心・ズーム・パン/ズーム操作・表示範囲が変わらない。

## 2. 表示品質

- [ ] 2.1 航空写真選択時、タイル（JPEG）が**欠落なく**表示される。
- [ ] 2.2 白地図選択時、ズームを 14 超へ上げても**空白で埋め尽くされず**地図内容が保たれる（最深タイルの引き伸ばし等）。
- [ ] 2.3 白地図選択時、表示位置を移動してもパン・ズーム操作が**破綻しない**（既存 maxBounds 内）。
- [ ] 2.4 各背景で、ズーム範囲・画像形式差に起因する明らかな**表示欠陥がない**。
- [ ] 2.5 任意背景で一部タイル取得に失敗しても地図全体がクラッシュ・操作不能にならず、**重畳レイヤ・現在地ナビが継続**動作する。

## 3. 出典（背景に追従）

- [ ] 3.1 **OSM 選択時**、出典に「OpenStreetMap contributors」と著作権リンク（`https://www.openstreetmap.org/copyright`）が表示される。
- [ ] 3.2 **地理院地図(標準)／航空写真／白地図のいずれか**選択時、出典に「出典：国土地理院ウェブサイト」と国土地理院サイトへのリンクが表示される。
- [ ] 3.3 OSM ↔ GSI を往復切替し、**切替前の背景の出典が残らない**（重複・混在しない）。
- [ ] 3.4 背景を切り替えても、重畳レイヤ（ハザード／指定緊急避難場所等）の出典は**継続表示**される。
- [ ] 4.3/4.4 出典リンクが正規の `https` リンクとして機能し、出典欄に**生 markup の崩れ・スクリプト注入痕がない**（DOM 上で `<a>` のラベルと href が分離、想定外タグ無し）。

> 注: 4.1/4.2（出典は開発者定数のみ・利用者/外部データ非補間）はコード経路の性質であり task 1.1 で実装・レビュー済み（純関数の両分岐を実証）。本実機項目は 4.3/4.4 の出力結果のみ目視確認する。
> 既知の意思決定: OSM 出典は安全ビルダ経由のため legacy 文字列の `©` グリフ無し・`http→https` 昇格。Req 3.1（contributors＋リンク）は充足。`©` をラベル先頭に付すかは人手判断の任意フォローアップ（BASEMAPS/1.2 の 1 行変更、本スコープ外）。

## 4. 非回帰

- [ ] 5.1 背景切替の前後で、重畳ハザード／指定緊急避難場所レイヤの**選択・可視・不透明度**が維持される。
- [ ] 5.2 背景切替の前後で、現在地取得・最寄り避難所ナビ・経路ライン・3D 地形/陰影が**従来どおり**動作する。
- [ ] 5.3 既存 OpacityControl（**左上**＝ハザード／**右上**＝指定緊急避難場所）と Geolocate/Terrain（**右下**）の位置・挙動が変わらない。
- [ ] 5.4 どの背景でも背景地図が重畳レイヤの**下**にあり、ハザード／避難場所／経路が背景に隠れず視認できる。
- [ ] 5.5 PWA のインストール可能性／オフライン挙動が従来どおり（manifest・Service Worker 挙動不変）。

## 5. アクセシビリティ

- [ ] 6.1 マウスを使わず **Tab／矢印キーのみ**で 4 種背景を選択・切替できる。
- [ ] 6.2 スクリーンリーダで各選択肢の**ラベルが読み上げ**られ、グループ見出し（「背景地図」）が認識される。
- [ ] 6.3 スクリーンリーダで現在の**選択状態（チェック）が判別**できる。
- [ ] 6.4 コントロールが地図のパン・ズーム操作を妨げず、既存コントロールと**重ならない**サイズ・位置。
