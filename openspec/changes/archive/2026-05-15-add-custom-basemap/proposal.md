## Why

現状の背景地図切替は OSM・地理院地図・航空写真・白地図の 4 種類のプリセットに固定されており、ユーザーが業務や用途に応じて自前のタイルサービス（例: 自治体公開タイル、独自 XYZ サーバ、契約済みのサードパーティタイル）を一時的に重ねて見るには、ソースコードを直接編集する以外の手段がない。ブラウザ完結で背景地図を追加・保持できるようになると、開発者でないユーザーでも地図の用途を拡張でき、再アクセス時にも追加した地図が失われない体験を提供できる。

## What Changes

- 背景地図切替コントロール（左下）の一覧末尾に「背景地図を追加」ボタンを追加する。
- 追加ボタン押下で表示される追加フォーム（モーダルダイアログ）から、名称・タイル URL・出典テキスト・出典リンク URL・（オプションで）minzoom・maxzoom を入力して、ユーザー独自の背景地図を登録できるようにする。
- 出典は **テキスト** と **リンク URL** の 2 入力に分離し、レンダリング時にアプリ側で `<a href="...">テキスト</a>` 形式に組み立てる（XSS 対策のため HTML はユーザーから受け取らない）。
- 入力された背景地図はブラウザの IndexedDB に永続化し、再アクセス時にも復元する。
- ユーザー追加の各背景地図行に操作メニュー（`⋮`）を表示し、「編集」「削除」の 2 操作を提供する。削除は当該地図を一覧と IndexedDB から取り除く。編集は同一フォームを **編集モード** で再表示し、名称・出典テキスト・出典リンク URL・minzoom/maxzoom を変更できる。**タイル URL は編集対象外**（同 URL で別定義にしたい場合は新規追加で対応する）とする。
- 現在選択中の背景地図 ID も永続化し、再アクセス時に最後に選択していた背景地図（プリセット／ユーザー追加問わず）を初期表示として復元する。永続化が無い場合や対象 ID が見つからない場合は OSM にフォールバックする。
- **BREAKING（仕様レベル）**: 初期表示は OSM 固定 → 最後に選択した背景地図（無ければ OSM）に変更する。既存仕様の「初期表示は OSM である」Scenario が書き換わる。

## Capabilities

### New Capabilities

- なし（既存ケイパビリティ `basemap-switching` の拡張として扱う）

### Modified Capabilities

- `basemap-switching`: 「プリセット 4 種類のラジオ排他選択」から「プリセット 4 種類 + ユーザー追加の任意個」に拡張する。新規 Requirement として、追加・編集 UI（共通フォームの 2 モード運用）、入力検証（URL テンプレート / 必須項目 / 編集時のタイル URL ロック）、操作メニュー（`⋮`）からの編集・削除、IndexedDB への永続化（追加した背景地図の定義、および現在選択中の背景地図 ID）、選択中背景地図の初期復元の挙動を追加する。既存の「初期表示は OSM」要件は「最後に選択した背景地図（無ければ OSM）」に書き換える。

## Impact

- **コード**: `main.js` の `BasemapSwitcherControl` クラスを拡張（一覧再描画、追加ボタン、各行の操作メニュー `⋮`、追加／編集兼用フォームダイアログ）。MapLibre の `style` 初期定義に頼っていた背景レイヤー登録を、ランタイムでの `map.addSource()` / `map.addLayer()` 呼び出しでも追加可能な形に拡張。編集保存時は同一 ID で source／layer を作り直す統一フローとする（タイル URL 不変のためタイルキャッシュは温存される）。
- **永続化レイヤー**: 新規モジュール（IndexedDB ラッパ）を追加。`idb-keyval`（軽量・依存ゼロに近い）を採用する想定。`package.json` の dependencies が 1 件増える。
- **スタイル**: 追加／編集フォーム（`<dialog>`）・操作メニュー（`⋮` および展開時のドロップダウン）・追加ボタンの CSS を `style.css` に追加。
- **既存仕様**: `openspec/specs/basemap-switching/spec.md` に対する delta（新規 Requirement の追加・既存 Requirement の修正）を生成。
- **互換性**: 既存のプリセット 4 種類の挙動・出典・ズーム範囲は不変。ハザード／指定緊急避難場所／3D 地形などの既存機能には影響しない（背景レイヤーの順序ルールに準拠する形でユーザー追加分を挿入する設計とする）。
