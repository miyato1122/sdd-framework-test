## ADDED Requirements

### Requirement: 災害情報統合コントロールは地図の左上に配置される

システムは、災害想定区域レイヤーと指定緊急避難場所レイヤーの表示切替 UI を 1 つに統合した「災害情報統合コントロール」を、地図の左上（MapLibre の `top-left` 位置）に配置しなければならない（SHALL）。本コントロールは MapLibre 標準の他コントロール（背景地図切替コントロール（左下）、`GeolocateControl`（右下）、`TerrainControl`（右下）、attribution（右下））と視覚的に重なってはならない（MUST NOT）。

本変更後、地図の右上には独立した災害情報・避難所関連のコントロールを配置してはならない（MUST NOT）。

#### Scenario: コントロールが左上に配置される

- **WHEN** 地図の描画が完了している
- **THEN** 災害情報統合コントロールが地図ビューの左上に表示されており、左下の背景地図切替コントロール、右下の GeolocateControl・TerrainControl・attribution と重なっていない

#### Scenario: 右上には災害情報関連のコントロールが存在しない

- **WHEN** 地図の描画が完了している
- **THEN** 地図ビューの右上に災害想定区域・指定緊急避難場所いずれのコントロールも表示されていない

### Requirement: コントロールは MapLibre 標準のコントロール外観に揃う

システムは、災害情報統合コントロールのルート要素に MapLibre 標準のコントロールクラス（`maplibregl-ctrl maplibregl-ctrl-group`）を付与し、白い角丸カードに沿った外観で表示しなければならない（SHALL）。本アプリの他の自作コントロール（背景地図切替コントロール）および MapLibre 標準コントロールと、視覚的に揃った見た目になっていなければならない（SHALL）。

#### Scenario: コントロールが MapLibre 標準コントロール外観で描画される

- **WHEN** コントロールが描画されている
- **THEN** コンテナ要素は `maplibregl-ctrl maplibregl-ctrl-group` クラスを持ち、白い角丸カードに沿った外観で表示される

### Requirement: コントロールは「災害想定区域」「避難所」の 2 セクションを縦並びで含む

システムは、災害情報統合コントロールの内部に「災害想定区域」セクションと「避難所」セクションの 2 つを、上から下へこの順で縦並びに配置しなければならない（SHALL）。各セクションには、ユーザーが一目でどちらのレイヤー群を操作しているかを判別できるよう、セクション名を表す見出し（"災害想定区域" / "避難所"）を表示しなければならない（SHALL）。両セクションの間には、視覚的に境界が分かる区切り線または十分な余白を設けなければならない（SHALL）。

#### Scenario: 災害想定区域セクションが上、避難所セクションが下に並ぶ

- **WHEN** 災害情報統合コントロールが描画されている
- **THEN** 「災害想定区域」見出しおよびその選択肢一覧が上段に、「避難所」見出しおよびその選択肢一覧が下段に表示され、両者の間に区切り線または十分な余白による境界がある

#### Scenario: 各セクションに見出しが表示される

- **WHEN** 災害情報統合コントロールが描画されている
- **THEN** コントロール内に「災害想定区域」と「避難所」の 2 つのセクション見出しテキストが含まれている

### Requirement: 災害想定区域セクションは 6 種類のレイヤーを排他選択できる

システムは、災害想定区域セクションに、以下 6 種類のレイヤーをラジオで排他選択する UI を提供しなければならない（SHALL）。同時に複数の災害想定区域レイヤーが可視であってはならない（MUST NOT）。

| 表示ラベル | 対応レイヤー ID |
| --- | --- |
| 洪水浸水想定区域 | `hazard_flood-layer` |
| 高潮浸水想定区域 | `hazard_hightide-layer` |
| 津波浸水想定区域 | `hazard_tsunami-layer` |
| 土石流警戒区域 | `hazard_doseki-layer` |
| 急傾斜警戒区域 | `hazard_kyukeisha-layer` |
| 地滑り警戒区域 | `hazard_jisuberi-layer` |

加えて、いずれの災害想定区域レイヤーも表示しない「なし」状態を選べる UI を提供しなければならない（SHALL）。「なし」を選択した場合、上表の 6 レイヤーすべてが地図上に描画されてはならない（MUST NOT）。

#### Scenario: 災害想定区域セクションから洪水を選択すると洪水レイヤーが表示される

- **WHEN** ユーザーが災害想定区域セクションで「洪水浸水想定区域」のラジオを選択する
- **THEN** `hazard_flood-layer` が地図上に描画され、`hazard_hightide-layer` / `hazard_tsunami-layer` / `hazard_doseki-layer` / `hazard_kyukeisha-layer` / `hazard_jisuberi-layer` はいずれも描画されていない

#### Scenario: 災害想定区域セクションから別の災害種別へ切り替えると排他的に切り替わる

- **WHEN** 洪水浸水想定区域を選択中の状態で、ユーザーが「津波浸水想定区域」のラジオを選択する
- **THEN** `hazard_tsunami-layer` のみが地図上に描画され、`hazard_flood-layer` を含む他 5 種類の災害想定区域レイヤーは描画されていない

#### Scenario: 災害想定区域セクションで「なし」を選択すると全災害想定区域レイヤーが消える

- **WHEN** 任意の災害想定区域を選択中の状態で、ユーザーが「なし」のラジオを選択する
- **THEN** 6 種類の災害想定区域レイヤー（`hazard_flood-layer` 〜 `hazard_jisuberi-layer`）はいずれも地図上に描画されていない

### Requirement: 避難所セクションは 8 種類のレイヤーを排他選択できる

システムは、避難所セクションに、以下 8 種類のレイヤーをラジオで排他選択する UI を提供しなければならない（SHALL）。同時に複数の避難所レイヤーが可視であってはならない（MUST NOT）。

| 表示ラベル | 対応レイヤー ID |
| --- | --- |
| 洪水 | `skhb-1-layer` |
| 崖崩れ/土石流/地滑り | `skhb-2-layer` |
| 高潮 | `skhb-3-layer` |
| 地震 | `skhb-4-layer` |
| 津波 | `skhb-5-layer` |
| 大規模な火事 | `skhb-6-layer` |
| 内水氾濫 | `skhb-7-layer` |
| 火山現象 | `skhb-8-layer` |

加えて、いずれの避難所レイヤーも表示しない「なし」状態を選べる UI を提供しなければならない（SHALL）。「なし」を選択した場合、上表の 8 レイヤーすべてが地図上に描画されてはならない（MUST NOT）。

#### Scenario: 避難所セクションから津波を選択すると津波対応の避難所レイヤーが表示される

- **WHEN** ユーザーが避難所セクションで「津波」のラジオを選択する
- **THEN** `skhb-5-layer` が地図上に描画され、`skhb-1-layer` から `skhb-8-layer` のうち `skhb-5-layer` 以外の 7 つはいずれも描画されていない

#### Scenario: 避難所セクションから別の災害種別へ切り替えると排他的に切り替わる

- **WHEN** 避難所セクションで「洪水」を選択中の状態で、ユーザーが「地震」のラジオを選択する
- **THEN** `skhb-4-layer` のみが地図上に描画され、`skhb-1-layer` を含む他 7 種類の避難所レイヤーは描画されていない

#### Scenario: 避難所セクションで「なし」を選択すると全避難所レイヤーが消える

- **WHEN** 任意の避難所レイヤーを選択中の状態で、ユーザーが「なし」のラジオを選択する
- **THEN** 8 種類の避難所レイヤー（`skhb-1-layer` 〜 `skhb-8-layer`）はいずれも地図上に描画されていない

### Requirement: 災害想定区域セクションと避難所セクションは互いに独立して操作できる

システムは、災害情報統合コントロール内の災害想定区域セクションと避難所セクションを、互いに独立した排他選択として扱わなければならない（SHALL）。一方のセクションでの選択操作が、他方のセクションの選択状態を変更してはならない（MUST NOT）。

#### Scenario: 災害想定区域の選択は避難所の選択に影響しない

- **WHEN** 避難所セクションで「津波」を選択中の状態で、ユーザーが災害想定区域セクションで「津波浸水想定区域」を選択する
- **THEN** `hazard_tsunami-layer` と `skhb-5-layer` が同時に地図上に描画され、避難所セクションの選択状態は「津波」のまま維持されている

#### Scenario: 避難所の選択は災害想定区域の選択に影響しない

- **WHEN** 災害想定区域セクションで「洪水浸水想定区域」を選択中の状態で、ユーザーが避難所セクションで「洪水」を選択する
- **THEN** `hazard_flood-layer` と `skhb-1-layer` が同時に地図上に描画され、災害想定区域セクションの選択状態は「洪水浸水想定区域」のまま維持されている

### Requirement: 初回ロード時は両セクションとも「なし」が選択された状態である

システムは、ページ読み込み直後の地図描画完了時点で、災害情報統合コントロールの災害想定区域セクション・避難所セクション両方で「なし」が選択された状態としなければならない（SHALL）。この時点で、災害想定区域 6 種・避難所 8 種のいずれのレイヤーも地図上に描画されていてはならない（MUST NOT）。

#### Scenario: 初回ロード時は何も表示されていない

- **WHEN** ページを新規に読み込み、地図の描画が完了する
- **THEN** 災害想定区域セクション・避難所セクションともに「なし」のラジオが選択（checked）された状態であり、`hazard_*-layer` および `skhb-*-layer` のいずれも地図上に描画されていない

### Requirement: 統合コントロールでの切替は既存のクリック・ホバー・現在地ライン挙動と整合する

システムは、災害情報統合コントロールの避難所セクションで選択されたレイヤーに対し、既存の以下の挙動が従来どおり機能するようにしなければならない（SHALL）:

- 避難所地物に対するクリック時のポップアップ表示（名称・住所・備考・対応災害種別）
- 避難所地物上でのホバー時のカーソル変更（`pointer`）
- ズーム 7 以上における「現在地 → 最寄り避難場所」ライン（`route-layer`）の描画。最寄り判定は、避難所セクションで現在選択中のレイヤーに含まれる地物に対して行われる

避難所セクションで「なし」が選択されている場合、上記いずれの挙動も発火してはならない（MUST NOT）。

#### Scenario: 避難所を選択中にクリックするとポップアップが表示される

- **WHEN** 避難所セクションで「地震」を選択した状態で、地図上の `skhb-4-layer` 地物が描画されている位置をクリックする
- **THEN** その地物の名称・住所・備考・対応災害種別を含むポップアップが表示される

#### Scenario: 避難所が「なし」のときはクリックしてもポップアップが出ない

- **WHEN** 避難所セクションで「なし」が選択された状態で、`skhb-*-layer` 地物がもともと存在していた地点をクリックする
- **THEN** ポップアップは表示されず、`queryRenderedFeatures` の結果が空である

#### Scenario: 避難所選択時にズーム 7 以上で現在地ラインが描画される

- **WHEN** ブラウザの位置情報を許可し、避難所セクションで任意のレイヤー（例: 「津波」）を選択した状態で、地図ズームを 7 以上に拡大する
- **THEN** 現在地と、選択中の `skhb-5-layer`（津波の場合）内で最も近い地物との間に青いライン（`route-layer`）が描画される
