## Notes

- 本機能は「保守タスク（依存ライブラリの最新化）」であり、対象パッケージ名
  （`vite`, `maplibre-gl` 等）および `npm run build` / `npm run dev` といった
  検証コマンドは、スコープと検証可能性を表すために不可避的に記述している。
  これらは「実装手段の指定（HOW）」ではなく、本タスクにおける検証対象そのもの
  （WHAT）であるため、Content Quality / 技術非依存の各項目は本タスクの性質を
  踏まえて PASS と判定した。
- 自動テストスイートが現状存在しないため、回帰検証は「ビルド成功＋手動スモーク」
  （憲章 II の手動スモーク手順）で行う前提を Assumptions に明記済み。
- すべての項目が PASS。`/speckit-clarify`（任意）または `/speckit-plan` へ進行可能。
