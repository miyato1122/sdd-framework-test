# 振る舞い契約: アップグレード前後の機能等価

本アプリは外部公開 API を持たない（フロントエンド単体）。本タスクにおける
「契約」は **既存アプリの観測可能な振る舞いがアップグレード前後で等価である
こと**。以下はリリース前に必須の手動スモークチェックリスト（憲章 II の
「文書化された手動スモーク手順」、憲章 III の UX 一貫性に対応）。

## 前提

- `npm ci`（または `npm install`）→ `npm run dev` で起動した状態。
- 比較基準: アップグレード**前**の挙動（必要なら別 worktree / git stash で
  旧 `package.json` のビルドを並走確認）。
- 合格条件: 各項目 PASS かつ **新規コンソールエラー 0 件**。

## スモークチェックリスト

| ID | 手順 | 期待結果 | 結果 |
|---|---|---|---|
| C1 | アプリを開く | 中心[138,37]/zoom5 で OSM 背景地図が表示。範囲外へパンできない（maxBounds） | ☐ |
| C2 | 左上コントロール操作 | 6 ハザード(洪水/高潮/津波/土石流/急傾斜/地滑り)を切替・不透明度変更でき、重畳表示される | ☐ |
| C3 | 右上コントロール操作 | 災害種別 8 種で skhb 円レイヤーが切替表示される | ☐ |
| C4 | skhb の点をクリック | 名称・住所・備考・対応災害（非対応はグレー）を含むポップアップ表示（最大幅 400px） | ☐ |
| C5 | skhb 上でマウス移動 | カーソルが pointer、外すと既定に戻る | ☐ |
| C6 | 右下 GeolocateControl を ON | 現在地取得・追従が動作（許可時） | ☐ |
| C7 | zoom≥7 かつ現在地 ON | 現在地と最寄り skhb を結ぶ青線(色 `#33aaff`/幅4)が描画。種別切替で最寄りが追従 | ☐ |
| C8 | zoom<7 へ縮小 / Geolocate OFF | 青線が消える | ☐ |
| C9 | TerrainControl(3D) をトグル | 3D 地形が有効化/解除。陰影図(hillshade)が地滑りレイヤー手前に表示 | ☐ |
| C10 | `npm run build` → 生成物を簡易配信 | 相対パス(`--base=./`)で表示。PWA: `manifest.json` 読込・`sw.js` 登録（DevTools Application）が回帰しない | ☐ |
| C11 | コンソール | 致命的エラー・新規 deprecation 0 件（許容できる警告は research/README に記録） | ☐ |

## 自動検証（補完）

- `tests/unit`: 最寄り施設選定ロジック（B8 / B7 の距離計算）が、固定の
  ジオメトリ入力に対しアップグレード前と同一の選定結果を返すこと。
  `@turf/distance` v7（named import）で値が変わらないことを保証。

## 性能（憲章 IV、quickstart に手順）

- 初回操作可能までの体感 < 3 秒、パン/ズームに目立つカクつきがない。
- 本番バンドルサイズをアップグレード前後で比較し、合理的範囲を超える増加が
  ないこと（増加時は理由を記録）。
