# クイックスタート（Phase 1）: 背景地図の切り替え

新規ライブラリ追加なし。現行依存（`maplibre-gl` / `maplibre-gl-opacity` ほか）のみで動作する。

## 前提
- Node.js `^20.19.0 || >=22.12.0`、依存導入済み（`npm install`）。`package-lock.json` は変更しない。

## 開発サーバ
```bash
npm run dev      # Vite。ブラウザで地図表示
```
- 地図**左下**に背景地図スイッチャー（OSM／地理院地図（標準地図）／航空写真／白地図）。初期は OSM 選択。

## 品質ゲート（マージ前・憲章 II / ワークフロー）
```bash
npm run test     # node --test（basemaps.js の決定論的ユニットテスト含む。実ネットワーク非依存）
npm run build    # vite build --base=./（成功が必須ゲート）
```
- Lint/Format は既存ツール設定に従いクリーンであること。

## 手動スモーク（描画経路・憲章 II が要求）
ユニット化できない地図描画/コントロール挙動は以下を目視確認する。

| # | 操作 | 期待（対応） |
|---|------|------|
| 1 | 初回表示 | 背景=OSM、左下にスイッチャー、コンソールエラーなし（US3-AC1 / SC-006） |
| 2 | 「航空写真」を選択 | 背景が航空写真へ即時切替、現在選択が航空写真表示、出典が「地理院タイル（国土地理院）」＋一覧リンクへ入替（US1-AC1 / US2 / SC-001/002/003） |
| 3 | 「地理院地図（標準地図）」「白地図」を順に選択 | 各背景へ即時切替、出典は国土地理院由来のまま（US1-AC2 / US2） |
| 4 | 「白地図」で最大ズームまで拡大 | z15–18 は z14 のオーバーズーム描画で破綻なし・操作継続（R2 / エッジケース） |
| 5 | 「OSM」へ戻す | 背景 OSM、出典が OpenStreetMap 由来へ入替（US2-AC2） |
| 6 | 現在選択中と同じ項目を再選択 | 無変化・無エラー・表示崩れなし（US1-AC3） |
| 7 | 短時間に4種を高速連続切替 | 最終選択と背景・出典が一致、途中状態が残らない（エッジケース） |
| 8 | オフライン化等でタイル取得失敗 | 失敗が可視化され、地図のズーム/パンは継続可能（FR-010 / SC-005 / 憲章 III） |
| 9 | ズーム/パン操作 | 左下スイッチャーが操作を妨げず、コントロール自身も操作可（US3-AC3） |
| 10 | ページ再読込 | 背景が OSM に戻る（US3-AC2、永続化なし） |

## 既知の制限（演習判断・未修正）

- 背景スイッチャーの**ラベル文字クリックではラジオが切り替わらない**（ラジオボタン本体のクリックは正常）。`maplibre-gl-opacity` 1.8.0 のソース上は `label[for]` 関連付けがあるが、実機では非作動を確認。本リポジトリは SDD 演習素材のため**今回は修正しない判断**（要望: 検証目的優先）。FR-001/003/008 はラジオ本体操作で充足。再対応する場合は実機 DOM 検証のうえ、二重トグルを避けた方式で行うこと。

## 影響範囲（最小）
- `basemaps.js`（新規・純粋）／`main.js`（GSI3ソース・3レイヤー追加＋背景 OpacityControl を bottom-left 追加＋`map.on('error')`）／`tests/unit/basemaps.test.mjs`（新規）。
- `index.html` / `style.css` / `opacity-control.css` / `public/sw.js` は原則変更なし（必要な微調整は共有 CSS のみ・インライン禁止）。
