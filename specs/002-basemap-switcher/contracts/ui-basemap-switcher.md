# 契約: 背景地図スイッチャー UI 挙動

`main.js` が `basemaps.js` と既存 `maplibre-gl-opacity` を結線して満たす UI 契約。新規依存なし。

## 配置・構成契約（FR-001/002/008/009）
- 背景用 `OpacityControl` を `map.addControl(ctrl, 'bottom-left')` で**地図左下**に常時表示。
- `baseLayers = buildBaseLayers()`（4択：OSM／地理院地図（標準地図）／航空写真／白地図）。
- ラジオ描画で**排他選択**、現在選択がラジオ選択状態で識別可能。
- スタイルは共有 `opacity-control.css`（`#opacity-control`）を流用。インラインスタイル不使用（憲章 III）。
- 他コントロールと非衝突：ハザード=top-left、skhb=top-right、Geolocate/Terrain=bottom-right、本機能=bottom-left。

## 切替挙動契約（FR-003/004）
- 起動・再読込直後: `osm-layer` 可視、`gsi-*-layer` は `visibility:'none'`、ラジオは OSM 選択（`getDefaultBasemapId()`）。
- 選択肢を選ぶと当該背景レイヤーのみ可視、他背景は不可視へ即時切替（体感3秒以内＝SC-001）。
- 現在選択と同じものを選んでも無変化・無エラー（US1-AC3）。

## 出典契約（FR-005/006/007）
- 出典は MapLibre 既定 `AttributionControl`（自動付与）が**可視ソースの `attribution` を集約**して表示。
- 背景切替で表示出典が自動入替：OSM 選択時=OpenStreetMap 由来、GSI 各種選択時=「地理院タイル（国土地理院）」＋一覧ページリンク。
- 重畳中オーバーレイ（ハザード等）の出典が併記されるのは正しい挙動（背景出典が提供元一致していれば SC-002 充足）。

## エラー挙動契約（FR-010・憲章 III）
- `map.on('error', …)` でタイル/ソース失敗を**非ブロッキングに可視化**（控えめな短時間通知）。
- 失敗時も地図のズーム/パンは継続可能（全画面ブロック・レイアウト破壊禁止、`current` 不変）。
- `console` のみの出力で握りつぶさない（利用者が状況を認識できること）。
